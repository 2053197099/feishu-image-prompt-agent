# 飞书图片与提示词素材整理

东方图库的独立素材整理 Agent 项目。用户将筛选好的角色图、场景图和提示词放入飞书表格后，本项目负责授权读取、确认配对与顺序，再交接给 `image-prompt-layout` 输出上图下文的 PNG 作品集。

**当前状态：项目入口已建立，飞书尚未连接。** 本仓库不含 API 客户端或凭据，不能声称已能读取实际表格。

## 后续接入需要的信息

- 表格链接及类型：飞书多维表格或电子表格。
- 用户指定的表/视图、筛选范围和记录顺序。
- 图片、提示词等字段的对应关系。
- 用户选择的授权方式与最小必要读取权限；通过连接器或云端秘密配置提供，不写进仓库。

字段建议（实际列名可映射）：记录 ID、图片附件、提示词原文、作品名称、类别（角色/场景）、是否入选、排序、说明。明确只读入选视图时，不强制再添加“是否入选”列。

## 使用入口

> 这是我的飞书表格，请先确认表格类型、字段映射和只读接入方式，然后整理我指定的入选记录，交接给图文排版项目。

缺图、空提示词、一行多附件或配对不明的记录需报告，不静默跳过或猜测。多个对话使用独立工作目录，素材须显式传递，不能把一个任务中的路径直接交给另一个任务。

项目规范见 `AGENTS.md`，统一数据格式见 `handoff-format.md`。用户素材、导出表格、附件和秘密不提交。
